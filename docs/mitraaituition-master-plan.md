# mitraaituition.com — AI Hindi Tuition Master Plan

> Purpose of this document: Use this as the starting blueprint for a new AI-assisted tuition platform focused first on elementary Hindi recovery learning for school children in India.

---

## 1. Genuine Product Call

This idea is strong, but it should start narrow.

The best first version is not "all subjects, Grade 1 to 10". That is too large, needs board-wise accuracy, and will slow launch. The strongest first product is:

**Elementary Hindi Catch-Up Tuition for children who missed basics.**

| Question | Answer |
|---|---|
| Does the idea work? | Yes, if it starts with elementary Hindi foundations instead of all Grade 1-10 subjects. |
| Why it can work | Many Indian children move schools, miss classes, change boards, or fall behind in Hindi basics. Parents need gentle recovery learning. |
| First learner | Grade 2-6 child who cannot confidently read, pronounce, write, or understand basic Hindi. |
| First buyer | Parent who wants low-pressure home practice before or alongside school tuition. |
| Core promise | Colorful Hindi basics explained slowly with voice, repetition, writing practice, and small quizzes. |
| Best launch scope | Hindi letters, matras/barakhadi, numbers, words, simple sentences, reading, dictation, and beginner writing. |
| Risk | Must not claim guaranteed school marks. Must align content carefully with class level and have human review. |

The emotional reason is also strong: this is for children who are not weak, but who missed learning at the right time. The product tone should never shame the child. It should feel like, "No problem, we will rebuild slowly."

Relationship to mitraailife.com:
- Same founder and Mitra brand family.
- Separate domain and repo because the audience is children and parents.
- Shared infrastructure can be reused, but child safety and privacy rules must be stricter.
- This is not the same as mitraaistudent.com. Student AI literacy teaches students about AI; this platform teaches school subjects using AI-assisted content.

### Strategy update

The product should not start as a class-wise Hindi syllabus.

Primary model: mastery-based learning flow from zero to fluent reading, writing, and speaking.

Reason:
- a child in Class 5 may still need alphabet or barakhadi repair work
- class labels can create shame or confusion if the learner is older than the content label
- Hindi learning is cumulative, so the right path is skill progression, not school-grade progression

Use class labels only later as wrappers, mapping guides, or recommended entry points.

Core promise of the track:

**Take a learner from zero confidence to strong Hindi reading, writing, vocabulary, grammar, and everyday speaking through repetition-heavy audio-visual learning.**

Secondary future audience after child validation:
- teenagers or adults who can read some Hindi but lack speaking confidence
- learners whose main gap is grammar, sentence formation, or vocabulary, not alphabet recognition

## 3. First MVP Recommendation

Build only **H1 + H2** first.

### MVP Name

**Hindi Catch-Up: Start From Zero**

### MVP Learner Outcome

After the MVP, a child should be able to:
- recognize basic Hindi vowels and consonants
- pronounce letters slowly and clearly
- identify matras in simple words
- read beginner words
- write letters on paper after watching stroke guidance
- answer small sound and letter quizzes

### MVP video principle

The first product wins or fails on audio-visual repetition quality.

For early alphabet and sound lessons:
- show one large colorful letter at a time
- repeat the sound 5 to 7 times slowly
- pair the letter with one familiar image and one anchor word
- example: आ → आम with mango image on screen
- keep the child in listen-first mode before testing

This is not just "watch and move on" content. It should feel like guided listening practice.

### MVP Lessons

| Lesson | Topic | Video Style | Practice |
|---|---|---|---|
| H1-01 | Hindi is for me — no-shame start | Friendly story, no pressure | Listen and repeat |
| H1-02 | Swar Set 1 | One letter at a time, repeated 5 to 7 times, image anchor | Trace on paper |
| H1-03 | Swar Set 2 | One letter at a time, repeated 5 to 7 times, image anchor | Match sound to letter |
| H1-04 | First sound confidence check | Listening game + visual support | Parent-assisted review |
| H2-01 | Vyanjan Part 1 | Letter + object + sound + repeat loop | Match sound to letter |
| H2-02 | Vyanjan Part 2 | Slow pronunciation + mouth pacing | Choose correct letter |
| H2-03 | Vyanjan Part 3 | Practice with examples + image anchors | Write 5 letters |
| H2-04 | Letter hunt and tracing | Revision loop + visual grouping | Find and write letters |

Do not start with grammar, essay writing, or unseen passage. Those come after reading confidence.

## 4. Curriculum Ladder

### Main curriculum rule

Build the core Hindi product as one continuous ladder.

Do not force the learner to choose "Class 1 Hindi", "Class 2 Hindi", or "Class 5 Hindi" at the start.

Instead:
- start with a short entry check
- place the learner at the right skill point
- let them skip what they already know
- let them repair weak basics without shame

Later, create class-wise mapping tables such as:
- "Usually secure by Class 2"
- "Usually secure by Class 5"
- "Useful revision for Class 6+"

The learning path itself should stay mastery-based.

### Track A: Hindi Foundation

| Level | Name | Child Skill |
|---|---|---|
| H1 | Start From Zero | Child feels safe, starts listening, and begins sound familiarity |
| H2 | Letters and Sounds | Recognize and pronounce swar and vyanjan |
| H3 | Barakhadi Foundations | Understand how matras change sounds |
| H4 | Barakhadi Mastery + Numbers | Read common barakhadi patterns and early numbers |
| H5 | Vocabulary and Word Reading | Recognize common words and daily objects |
| H6 | Everyday Sentences and Speaking | Speak and write useful daily-life Hindi |

### Track B: School Hindi Basics

| Level | Name | Child Skill |
|---|---|---|
| H7 | Everyday Hindi Grammar | Sangya, sarvanam, kriya, ling, vachan, ka/ki/ke, ko, ne, se |
| H8 | Reading and Comprehension | Read small passages and answer questions |
| H9 | Creative and Functional Writing | Picture writing, paragraph writing, letter writing |
| H10 | Independent Expression | Essay writing, imagination writing, and confident speaking/writing |

### Zero-to-Hero Hindi Flow

This is the full intended outcome for the platform:

1. hear and distinguish Hindi sounds clearly
2. recognize swar and vyanjan confidently
3. connect letters with image anchors and familiar words
4. master barakhadi through repeated listening and visual patterns
5. read number symbols and number words
6. build daily-life vocabulary with pictures and repetition
7. read small words smoothly
8. form simple sentences for home, school, market, travel, and feelings
9. understand grammar patterns that usually confuse learners
10. write paragraphs, letters, and essays with imagination and confidence
11. speak Hindi comfortably in daily life

That is the right final promise: not just passing a class, but reaching real Hindi ability.

### Track C: Grade-Wise Expansion Later

After the foundation track works, create board-aware packs:
- Grade 1 Hindi basics
- Grade 2 Hindi basics
- Grade 3 Hindi reading and writing
- Grade 4 grammar and paragraph writing
- Grade 5 unseen passage and composition
- Grade 6-8 grammar, comprehension, writing
- Grade 9-10 board-focused writing and exam prep

This should not be built first because every board and textbook differs.

The right order is:
- first build the skill ladder
- then map that ladder to school classes
- then publish class-wise recommendation pages if needed

## 5. What Makes Hindi Hard For Learners

The platform should explicitly focus on the parts that confuse learners most.

### Main confusion areas

- similar sounds that are hard to hear or pronounce correctly
- matra changes that alter the word form quickly
- barakhadi memorization without meaning
- grammar patterns like का / की / के
- postpositions like को / से / ने / में / पर
- masculine and feminine changes
- singular and plural changes
- lack of vocabulary for daily speaking
- fear of speaking wrong Hindi in front of others

### Product response

Do not teach grammar only as definitions.

Teach grammar through:
- picture examples
- object comparisons
- boy/girl examples
- one word changed in 3 forms
- daily-life sentence pairs
- contrast drills: यह लड़का / यह लड़की, मेरा कमरा / मेरी किताब

If the platform makes learners genuinely understand gender, agreement, and common sentence forms, that will be one of the strongest success factors.

## 6. Lesson Format

Each lesson should follow the same pattern.

| Part | Description |
|---|---|
| 1. Watch | 2-4 minute colorful video with slow pronunciation |
| 2. Repeat | Letter, sound, or word repeated 5 to 7 times where needed |
| 3. Trace | Child writes on paper while video pauses |
| 4. Listen | Audio says a sound or word |
| 5. Choose | Child selects from 3-4 options |
| 6. Write | Child writes in notebook; parent can mark done |
| 7. Tiny Win | Sticker/star/reward message |

### Video Style

- large letters on screen
- bright background, but not visually noisy
- one concept per screen
- pronunciation repeated slowly
- animations should show how a matra changes the sound
- alphabet lessons should pair letter + image + anchor word every time possible
- barakhadi lessons should visually connect base letter to all sound variations
- examples from Indian home and school life
- child-friendly voice, not robotic
- never say "wrong" harshly; say "try again"

### Video formats to build

- listen-only alphabet loops
- listen + look + repeat alphabet lessons
- barakhadi animation lessons
- picture vocabulary lessons
- number symbol lessons
- daily-life sentence roleplay lessons
- grammar contrast lessons
- slow reading practice videos
- dictation practice audio

### Quiz Types

- hear sound, choose letter
- see letter, choose sound
- see picture, choose word
- missing matra dropdown
- word ordering into sentence
- read passage, choose answer
- picture prompt, child writes in notebook

## 7. Vocabulary, Speaking, and Writing Progression

Hindi success is not only alphabet mastery. The platform must deliberately build vocabulary, speaking confidence, and writing range.

### Vocabulary plan

Create a large visual vocabulary bank across:
- home objects
- family words
- food and fruits
- school items
- colors and shapes
- actions
- feelings
- places
- time and numbers
- festivals and daily routines

Every vocabulary set should include:
- word in Devanagari
- pronunciation audio
- image
- one simple sentence
- one contrast example if grammar changes apply

### Speaking plan

Include a dedicated daily-life Hindi section with spoken-use sentences:
- greeting people
- asking for water, food, help, directions
- classroom speech
- market speech
- travel speech
- telling feelings, needs, and opinions

Goal: the learner should not only read Hindi, but use it.

### Writing plan

Writing should grow in this order:
- letter tracing
- single-word copying
- fill-in-the-matra
- sentence copying
- guided sentence creation
- picture description
- paragraph writing
- personal letter writing
- essay writing
- imagination writing on a topic

Poetry can be optional later. It should not be a core early promise.

## 9. Entry, Assessment, and Personalization

Every learner does not need the same starting point.

### Entry check

Create a short diagnostic with four parts:
- can the learner identify letters?
- can the learner read simple barakhadi forms?
- can the learner read basic words?
- can the learner form or understand simple sentences?

Based on the result, route them to:
- Start from Zero
- Barakhadi Repair
- Reading Repair
- Grammar and Sentence Repair

This solves the problem of older learners feeling they are in the wrong class.

### Future adult lane

After the child-first Hindi track proves useful, add a second Hindi confidence lane for teens and adults.

That lane should focus on:
- grammar repair
- daily-life speaking confidence
- vocabulary growth
- sentence correction
- reading and listening fluency

This is useful for adults who can read some Hindi but do not feel confident speaking it correctly.

## 11. Legal, Safety, and Ethics

This platform is for children, so safety is more important than speed.

Required rules:
- parent account, not direct child account, in the first version
- no public comments on child lesson pages
- no Disqus for children-facing pages
- no collection of child photos, voice, school name, or location in MVP
- no claim of guaranteed marks
- no medical or psychological claims
- human review before publishing every lesson
- parent guidance page: this is practice support, not a school replacement

If interactive voice recording is added later, get explicit parent consent and store minimal data.

1. Lesson 1: अ, आ, इ, ई
2. Lesson 2: क, ख, ग, घ
3. Lesson 3: क + matras intro
