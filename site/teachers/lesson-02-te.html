ChatGPT, Gemini, మరియు Claude Basics

చదవడానికి 7 నిమిషాలు · ఏ prior AI knowledge అవసరం లేదు · తెలుగు + English

మీరు నేర్చుకునేవి

  • ChatGPT, Gemini, Claude ని ఎలా తెరవాలి మరియు use చేయడం start చేయాలి
  • Teaching work కోసం ప్రతి tool దేనికి best
  • Beginner teacher గా ఏ tool తో start చేయాలి
  • Free మరియు paid versions మధ్య తేడా

Start చేయడానికి ఒక్క tool మాత్రమే అవసరం

చాలా AI tools ఉన్నాయి. కానీ teaching work కోసం, మూడు tools దాదాపు అన్నీ cover చేస్తాయి: ChatGPT, Gemini, Claude. మూడూ అవసరం లేదు. ఒకటి తో start చేయండి, comfortable అవ్వండి, తరువాత మిగతావి try చేయండి.

ChatGPT — అత్యంత widely used

Website: chat.openai.com
తయారుచేసినది: OpenAI (USA)
Free tier: ఉంది. మీ email తో free account create చేయండి. Free version (GPT-4o mini) lesson plans, worksheets, question papers కి సరిపోతుంది.
Teachers కి best: Lesson plans, worksheets, question papers, explanations, feedback comments, parent messages. అన్ని subjects మరియు class levels కి బాగా పనిచేస్తుంది.
ఎలా start చేయాలి: chat.openai.com కి వెళ్ళండి → Email తో sign up చేయండి → Chat box లో మీ request type చేయండి → Enter నొక్కండి.

చాలా teachers కి ChatGPT best starting tool ఎందుకంటే ఇది largest community మరియు online లో most examples కలిగి ఉంది. "ChatGPT prompt for teachers" search చేస్తే చాలా examples కనిపిస్తాయి.

Gemini — Google యొక్క AI tool

Website: gemini.google.com
తయారుచేసినది: Google
Free tier: ఉంది. మీ existing Google account తో sign in చేయండి. Gmail already use చేస్తుంటే కొత్త account అవసరం లేదు.
Teachers కి best: Quick lesson drafts, Google Docs integration, long text summarising, మరియు school లో Google Workspace use చేసే teachers.
ఎలా start చేయాలి: gemini.google.com కి వెళ్ళండి → Gmail తో sign in చేయండి → Request type చేయండి → Enter నొక్కండి. Google Docs sidebar లో కూడా available.

మీ school Google Classroom లేదా Google Docs use చేస్తుంటే, Gemini ఆ tools లోనే directly పనిచేస్తుంది కాబట్టి ప్రత్యేకంగా useful. Google ecosystem లో ఇప్పటికే ఉన్న teachers కి good choice.

Claude — long reference material కి best

Website: claude.ai
తయారుచేసినది: Anthropic (USA)
Free tier: ఉంది. Email తో free account create చేయండి. Free tier లో daily usage limit ఉంటుంది.
Teachers కి best: మొత్తం chapter, long syllabus, లేదా multiple pages of notes paste చేయాల్సి వచ్చినప్పుడు. Free tier లో Claude చాలా long text ని ఇతరుల కంటే better గా handle చేస్తుంది.
ఎలా start చేయాలి: claude.ai కి వెళ్ళండి → Sign up చేయండి → మీ reference material తో పాటు request paste చేయండి → Enter నొక్కండి.

ఎప్పుడైనా large amount of reference text paste చేయాల్సి వచ్చినప్పుడు — textbook నుండి మొత్తం chapter, full year syllabus — ఆ material లోనే stay కావడానికి Claude most reliable option.

మీరు ఏది తో start చేయాలి?

మీరు complete beginner అయితే ChatGPT తో start చేయండి. ఇది most documented మరియు teacher communities లో most commonly discussed AI tool.

మీ school Google Workspace use చేస్తుంటే మరియు కొత్త account create చేయకూడదు అనుకుంటే Gemini తో start చేయండి.

Long chapter లేదా syllabus ఉండి AI ని strictly ఆ material లోనే work చేయించాలనుకుంటే Claude use చేయండి.

Free vs paid — pay చేయాలా?

ఈ 8 lessons లో cover అయ్యే work కి — lesson plans, worksheets, question papers, feedback — ఈ tools లో దేనిదైనా free tier సరిపోతుంది. Start చేయడానికి pay చేయవలసిన అవసరం లేదు.

Paid versions ఎక్కువ usage, faster responses, advanced features ఇస్తాయి. ప్రతిరోజూ heavily use చేస్తే తరువాత upgrade చేయవచ్చు. ప్రస్తుతం, free తో start చేయండి.

Basic steps — మూడు tools కీ ఒకటే

ప్రతి conversation ఎలా పనిచేస్తుంది
Step 1: Website తెరిచి sign in చేయండి (లేదా free account create చేయండి) Step 2: ఒక text box కనిపిస్తుంది — ఇక్కడ మీ request type చేయండి Step 3: మీ request clearly type చేయండి (దీనినే "prompt" అంటారు) Step 4: Enter నొక్కండి లేదా send button click చేయండి Step 5: Output read చేయండి Step 6: Output సరిగ్గా లేకపోతే, అదే chat లో follow-up correction type చేయండి Step 7: మీకు అవసరమైనది copy చేసి use చేయడానికి ముందు check చేయండి
Try చేయడానికి ఒక simple first request
Create a 5-question quiz on the water cycle for Class 6 students. Include multiple choice questions with 4 options each. Add an answer key at the end. Keep language simple.
Quiz — The Water Cycle (Class 6) 1. What is the process by which water turns into water vapour called? a) Condensation b) Evaporation c) Precipitation d) Transpiration Answer: b) Evaporation 2. From where does most of the water in the water cycle come? a) Rivers b) Glaciers c) Oceans d) Lakes Answer: c) Oceans 3. What happens during condensation? a) Water evaporates from plants b) Water vapour cools and turns into clouds c) Rain falls on the ground d) Water soaks into the soil Answer: b) Water vapour cools and turns into clouds 4. What is the name of the process by which plants release water vapour? a) Evaporation b) Condensation c) Transpiration d) Infiltration Answer: c) Transpiration 5. Where does water go after it falls as rain on land? a) It stays on the surface forever b) It flows into rivers, soaks into soil, or evaporates again c) It immediately goes back into clouds d) It disappears into the ground permanently Answer: b) It flows into rivers, soaks into soil, or evaporates again [Teacher: verify answers against your Class 6 textbook chapter on water cycle before distributing]

AI output పొందిన తరువాత — ఎప్పుడూ check చేయండి

  • Facts correct గా ఉన్నాయా? Textbook తో 2–3 answers verify చేయండి.
  • Class level కి language సరిగ్గా ఉందా?
  • మీరు currently teach చేస్తున్న syllabus లోనే అన్ని questions ఉన్నాయా?
  • ఏ question wording అయినా మార్చాలనుకుంటారా? Use చేయడానికి ముందు మార్చండి.

Practice task

  1. ఒక tool ఎంచుకోండి: ChatGPT (chat.openai.com), Gemini (gemini.google.com), లేదా Claude (claude.ai).
  2. మీకు లేకపోతే free account create చేయండి. మీ email use చేయండి.
  3. ఈ prompt type చేయండి: "Create 5 true-or-false questions on the topic of respiration for Class 9 Biology. Include answers."
  4. Output read చేసి, ఏ answers keep చేస్తారో మరియు ఏవి మార్చుతారో mark చేయండి.
  5. రెండవ tool లో అదే prompt repeat చేసి రెండు outputs compare చేయండి.
