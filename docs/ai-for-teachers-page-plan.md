# AI for Teachers - Full Page and Curriculum Plan

> Purpose of this document: Plan the full `/teachers/` page for Mitra AI Life and define what teachers can learn in simple English before the page is built.

---

## 1. Track Decision

AI for Teachers is a practical learning track for school and college teachers who want to use AI to save time, prepare better classroom material, and support students more effectively.

This track belongs to the main Mitra AI Life platform under:

`/teachers/`

This is not a premium engineering project track. It is a teacher support and professional learning track.

Recommended launch language:

- English first
- Telugu later after the English content is reviewed

Recommended access model:

- First beginner lessons can be free
- Deeper workshops, templates, and institutional training can become paid later
- No payment pressure during early launch

## 3. Problem This Page Solves

Teachers spend a lot of time on repeated work:

- lesson planning
- worksheets
- question papers
- answer keys
- classroom activities
- revision notes
- student feedback
- parent communication
- presentation slides
- explaining hard topics in simple words

AI can help teachers do these tasks faster, but teachers need safe, practical, and clear guidance.

This page should show teachers how to use AI as a teaching assistant, not as a replacement for teacher judgment.

### Section 6: Prompt Engineering for Teachers

Teach a simple prompt formula:

**Role + task + class level + topic + reference material + output format + safety check**

Example:

```text
You are a Class 8 science teacher.
Create a 40-minute lesson plan on photosynthesis.
Use the reference notes below.
Keep the language simple.
Include 5 warm-up questions, 1 activity, 1 board summary, and 5 homework questions.
Do not add facts that are not supported by the reference notes.
```

- syllabus

Important rule:

AI can create a draft. The teacher must review, correct, balance, and approve the final paper.

## 11. Example Teacher Prompt Templates

### Lesson Plan Prompt

```text
You are an experienced school teacher.
Create a lesson plan for Class [class number] on [topic].
Use only the reference material below.
The class duration is [minutes].
Include learning outcomes, warm-up questions, explanation flow, board summary, activity, homework, and quick assessment.
Keep the language simple.
Reference material:
[paste material]
```

### Worksheet Prompt

```text
Create a worksheet for Class [class number] on [topic].
Use the reference material below.
Include 5 fill-in-the-blanks, 5 MCQs, 5 short-answer questions, and 2 application questions.
Add an answer key.
Do not include questions outside the reference material.
Reference material:
[paste material]
```

### Question Paper Prompt

```text
Create a draft question paper for Class [class number] on [subject].
Use the syllabus, old question paper pattern, and reference notes below.
Total marks: [marks]
Time: [time]
Difficulty: [easy/medium/hard mix]
Include a marks distribution table and answer key.
Do not copy the old paper directly.
Teacher review is required before final use.
Reference material:
[paste material]
```

### Feedback Prompt

```text
Create kind and useful feedback comments for students who made these common mistakes in [topic].
Keep the tone encouraging.
Give one improvement step for each mistake.
Do not include personal student details.
Common mistakes:
[paste mistakes]
```

## 12. Safety Checklist for Teachers

Before using AI output in class, the teacher should check:

- Is the answer factually correct?
- Is it suitable for the class level?
- Is the language clear?
- Is the question paper balanced?
- Are marks and difficulty levels fair?
- Did AI add content outside the reference material?
- Does the material respect student privacy?
- Does it follow school or college rules?
- Does the teacher approve the final version?

## 14. Legal and Ethical Risks

| Risk | Mitigation |
|---|---|
| Teachers upload private student data | Teach privacy rules clearly and avoid collecting student information |
| AI creates wrong facts | Add human review checklist to every workflow |
| Copyrighted textbook misuse | Teach teachers to follow school policy and copyright rules |
| Question papers become unfair | Require teacher review, blueprint check, and marks balance |
| Students misuse AI for cheating | Include honest AI use guidance for teachers to share |
| Schools think AI replaces teachers | Position AI as assistant, not replacement |
