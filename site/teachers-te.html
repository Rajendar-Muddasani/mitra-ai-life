Teachers కోసం simple prompt formula

మంచి prompt అంటే AI కి role, task, class level, topic, reference material, output format, మరియు safety instruction ఇవ్వడం. ఇది memorise చేయవలసిన అవసరం లేదు. ప్రతి సారి ఈ pattern follow చేయండి.

Formula
Role + Task + Class level + Topic + Reference material + Output format + Safety instruction
Example — Lesson plan prompt
You are an experienced Class 8 science teacher. Create a 40-minute lesson plan on photosynthesis. Use only the reference notes below. Keep the language simple enough for Class 8 students. Include: 5 warm-up questions, explanation flow, 1 hands-on activity, board summary, 5 homework questions. Do not add facts that are not in the reference notes. Reference notes: [మీ notes ఇక్కడ paste చేయండి]

Add a complete answer key. Do not include questions outside the reference material. Reference material: [మీ notes ఇక్కడ paste చేయండి]

Important rule

Include: 5 MCQs (1 mark each), 5 short-answer questions (2 marks each), 1 long-answer question (5 marks). Add a marks distribution table and answer key. Teachers కోసం safety మరియు ethics rules

ఈ rules students ని protect చేస్తాయి, teacher ని protect చేస్తాయి, classroom లో AI use ని honest గా ఉంచుతాయి.

  • ఏ public AI tool లోకి student personal details, names, లేదా sensitive records upload చేయవద్దు.
  • AI output ని blindly నమ్మవద్దు. Classroom use కి ముందు ఎల్లప్పుడూ human review చేయండి.
  • School policy మరియు copyright rules check చేయకుండా copyrighted textbooks మొత్తం public AI tools లోకి copy చేయవద్దు.
  • Manually check చేయకుండా unfair, biased, లేదా unbalanced assessment create చేయడానికి AI use చేయవద్దు.
  • AI output ని students కి guaranteed truth గా present చేయవద్దు. ఇది review చేసిన draft అని చెప్పండి.
  • AI tool use పై school లేదా institution policy ని bypass చేయవద్దు.
  • Teacher judgment లేకుండా individual student performance ని evaluate చేయడానికి AI use చేయవద్దు.
