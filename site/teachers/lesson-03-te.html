Teachers కోసం Simple Prompt Formula

చదవడానికి 8 నిమిషాలు · Lesson 2 పై build అవుతుంది · తెలుగు + English

మీరు నేర్చుకునేవి

  • Vague prompt vague result ఎందుకు ఇస్తుంది
  • ప్రతి teacher use చేయగల 7-part prompt formula
  • వేర్వేరు teaching tasks కోసం మూడు ready-to-use prompt examples
  • ఒక చిన్న change తో weak prompt ని ఎలా improve చేయాలి

మీ first prompt perfect గా ఎందుకు పనిచేయదు

చాలా teachers "make a worksheet on fractions for Class 6" అని type చేస్తారు మరియు output too easy, too hard, too long, లేదా right format లో లేకుండా వస్తుంది. Problem AI tool కాదు. Problem ఏమిటంటే prompt too vague.

AI కి తెలియాలి: మీరు ఎవరు, మీకు ఏం కావాలి, ఎవరి కోసం, ఏ level, ఏ format, ఏ limits లో stay కావాలి. ఈ విషయాలు మీరు ఎంత clearly చెబితే, output అంత better గా ఉంటుంది.

7-part prompt formula

Part 1 — Role: AI ఎవరిగా act చేయాలో చెప్పండి. "You are an experienced Class 8 Maths teacher."
Part 2 — Task: AI exactly ఏం create చేయాలో చెప్పండి. "Create a 40-minute lesson plan."
Part 3 — Class level: Grade మరియు subject specify చేయండి. "For Class 8 students studying CBSE Maths."
Part 4 — Topic: Topic గురించి specific గా ఉండండి. "On the topic: Linear Equations in One Variable."
Part 5 — Reference material: Prompt తరువాత మీ notes, chapter text, లేదా syllabus paste చేయండి. "Use only the reference material below."
Part 6 — Output format: మీకు ఏ sections కావాలో AI కి చెప్పండి. "Include: learning outcomes, warm-up, explanation steps, 1 activity, board summary, 5 homework questions."
Part 7 — Safety instruction: Limits set చేయండి. "Do not add content outside the reference material. Keep all examples simple and relevant to Indian students."

Weak prompt vs strong prompt — side by side

Weak prompt
Make a worksheet on fractions for Class 6.
Strong prompt (formula use చేస్తూ)
You are an experienced Class 6 Maths teacher. Create a worksheet on fractions for Class 6 CBSE students. Include: 5 fill-in-the-blank questions, 5 MCQs, 4 short-answer questions, 1 word problem using a real Indian daily-life situation. Add a complete answer key. Use only simple language suitable for Class 6. Do not include topics beyond the CBSE Class 6 fractions syllabus.

Strong prompt AI కి role, specific task, class level, topic, section counts తో output format, language requirement, scope limit ఇస్తుంది. Result more usable గా ఉంటుంది, చాలా తక్కువ corrections అవసరం అవుతాయి.

మూడు ready-to-use prompt templates

Template 1 — Lesson plan
You are an experienced [SUBJECT] teacher for [CLASS LEVEL]. Create a [DURATION]-minute lesson plan on [TOPIC]. Use only the reference material below. Include: learning outcomes (3 points), 3 warm-up questions, explanation flow, 1 classroom activity, board summary, 5 homework questions. Keep the language simple. Do not add content outside the reference material. Reference material: [PASTE YOUR NOTES HERE]
Template 2 — Worksheet with answer key
You are a [CLASS LEVEL] [SUBJECT] teacher. Create a worksheet on [TOPIC] for [CLASS LEVEL] students. Include: [N] fill-in-the-blanks, [N] MCQs (4 options each), [N] short-answer questions, [N] application/word problems. Add a complete answer key at the end. Use examples from Indian daily life where possible. Do not include content outside this syllabus point: [SYLLABUS POINT].
Template 3 — Simple explanation
Explain [CONCEPT] to a [CLASS LEVEL] student in India. Use very simple English. Use a real-life example that an Indian student in a [CITY/TOWN TYPE] school would understand. Keep the explanation to 3 short paragraphs. After the explanation, add 2 questions to check understanding.

Follow-up తో output ఎలా improve చేయాలి

First output సరిగ్గా లేకపోతే, మళ్ళీ start చేయవలసిన అవసరం లేదు. అదే chat window లో correction type చేయండి:

The word problems are too difficult for Class 6. Make them simpler and use examples about buying vegetables at a market or sharing rotis at lunch.

AI earlier conversation గుర్తుంచుకుంటుంది. మీకు అవసరమైనట్లుగా match అయ్యే వరకు అదే window లో refine చేయవచ్చు.

ఏ AI output అయినా use చేయడానికి ముందు

  • మీరు specify చేసిన topic మరియు class level లోనే AI stay అయిందా?
  • Facts మరియు answers correct గా ఉన్నాయా?
  • మీ students కి language appropriate గా ఉందా?
  • మీరు ఇచ్చిన reference material బయటకి AI వెళ్ళిందా?
  • ఏ question లేదా explanation wording అయినా మార్చాలనుకుంటారా?

Practice task

  1. మీరు currently teach చేస్తున్న class నుండి ఒక topic ఎంచుకోండి.
  2. 7-part formula use చేసి prompt రాయండి. అన్ని 7 parts fill చేయండి.
  3. Prompt ని ChatGPT లేదా Gemini లో paste చేయండి.
  4. Output read చేయండి. ఒక follow-up correction type చేయండి — format, difficulty, లేదా language గురించి ఏదైనా change చేయండి.
  5. First output మరియు second output compare చేయండి. ఒక correction ఎంత తేడా చేస్తుందో గమనించండి.
